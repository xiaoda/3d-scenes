# 中世纪小镇 P1：免费资产验证实施计划

> 2026-10-07｜用户已认可 P0，要求首轮仅免费资产。按 executing-plans 分批实施，不进入 P2。

> 2026-10-08 更新：用户暂无主建筑文件，选择先验证现有内容。批次二检查台已实现并完成本轮修复；批次三针对现有样本的验证与文档已完成。批次一的主建筑获取及 P1 整体视觉验收仍待完成。详见 [本轮检查记录](../reviews/2026-10-08-town-p1-qa.md)。

**目标：**实际导入建筑候选、石路及关键道具，提供可旋转、近看、换光的浏览器资产检查样板。资产不合格则记录失败，不伪称最终品质已通过。

**架构：**资产来源清单和静态文件独立；Three.js 只负责 glTF/FBX 的展示与材质验证。参考板继续保留。原始下载位于 asset-sources，运行资产位于 public/assets/town，下载与测试日志位于 .preview/town-p1-20261007。

**技术：**TypeScript、Vite、Three.js；不做物理、室内、完整街区、3DGS或公网部署。

## 批次一：获取与校验
- 核对 CC0/CC BY 原始来源和署名；登录下载、许可冲突、未知来源不强行获取。
- 先写 tests/assets.test.mjs 校验文件、哈希、关联资源、许可证。首次缺资产应失败。
- 获取一个建筑候选与 Poly Haven 石路、酒桶、门细部，保留原始文件及修改记录。
- 不合格或未取得建筑时保持 P1 未通过，不用代码生成占位建筑补数。

## 批次二：资产检查页
- 创建 package.json、tsconfig.json、index.html、src/main.ts、src/style.css、src/engine/renderer.ts、src/assets/catalog.ts。依赖固定版本。
- 创建纯逻辑测试（边界尺寸、纹理色彩空间策略和近景机位），再实现最小代码。
- 本地真实 3D 视口：整体/背面/近景、旋转缩放、日光/中性光、线框检查；显示来源、尺寸、网格和纹理信息。
- 加载失败/WebGL 不可用须明确提示，不显示伪造完成画面。

## 批次三：验证与交付
- 运行类型检查、测试和生产构建；仅监听127.0.0.1，隐藏启动、记录PID与真实端口。
- Chrome DevTools 独立页面检查截图、交互、网络、控制台；记录实际GPU，不把无头结果当用户显卡性能承诺。
- 写 docs/assets/town-sources.md、docs/reviews/2026-10-08-town-p1-qa.md，更新精简计划（验收记录按实际检查日期命名）。
- 交付实际资产的通过/保留/淘汰结论；用户审阅后再决定 P2。
